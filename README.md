# TV Capture

Chrome extension that captures trading setups from TradingView, analyzes them with AI, and sends structured messages to Telegram.

## Features

- 📸 Screenshot capture from TradingView
- 🤖 AI-powered trade setup analysis (planned)
- 📨 Send to Telegram with one click
- ⚙️ Configurable settings for Telegram bot

## Installation

See [INSTALL.md](./INSTALL.md) for detailed installation instructions.

## Development

```bash
# Install dependencies
pnpm install

# Development mode with HMR
pnpm dev

# Production build
pnpm build

# Build for distribution (.zip)
pnpm build:crx
```
