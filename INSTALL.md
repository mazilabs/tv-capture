# TV Capture – Installation Guide for Test Users

## Prerequisites

- Google Chrome browser (version 88 or newer)
- The `.crx` file or download link provided by the developer

---

## Step 1: Download the Extension

1. Click the download link provided by the developer
2. Save the `.crx` file to your computer (e.g., Downloads folder)

---

## Step 2: Open Chrome Extensions

1. Open Chrome
2. Type `chrome://extensions` in the address bar
3. Press Enter

---

## Step 3: Enable Developer Mode

1. Look for the toggle switch **"Developer mode"** in the top right corner
2. Toggle it **ON** (it should turn blue)

> ⚠️ **Note:** Chrome may show a warning about developer mode extensions. This is normal for extensions not from the Chrome Web Store. TV Capture is safe to use.

---

## Step 4: Install the Extension

### Method A: Drag and Drop (Recommended)

1. Locate the downloaded `.crx` file
2. Drag the file onto the `chrome://extensions` page
3. A dialog will appear asking to confirm
4. Click **"Add Extension"**

### Method B: Load Unpacked (Alternative)

1. If the `.crx` file doesn't install, rename it to `.zip`
2. Unzip the file to a folder
3. On the `chrome://extensions` page, click **"Load unpacked"**
4. Select the unzipped folder

---

## Step 5: Verify Installation

1. You should see "TV Capture" in your extensions list
2. The TV Capture icon should appear in your toolbar
3. Click the icon to open the popup

---

## Step 6: Configure Telegram (Required)

1. Click the extension icon
2. Click **"⚙ Settings"**
3. Enter your Telegram Bot Token and Chat ID
4. Click **"Save Settings"**

> 📖 See the developer's guide for how to create a Telegram bot and get your Chat ID.

---

## Automatic Updates

TV Capture checks for updates automatically every hour. When a new version is available:

1. A yellow banner appears in the popup: **"Update Available"**
2. Click **"Update Now"** to go to the release page
3. Download the new `.crx` file
4. Install it (Chrome will update automatically)

---

## Troubleshooting

### "This extension is not from the Chrome Web Store"

This is normal for self-hosted extensions. Click **"Continue"** or **"Keep anyway"** to proceed.

### Extension icon not visible

1. Click the puzzle piece icon 🧩 in the Chrome toolbar
2. Find "TV Capture"
3. Click the pin icon 📌 to keep it visible

### Extension not working

1. Go to `chrome://extensions`
2. Find TV Capture
3. Make sure the toggle is **ON**
4. Try clicking the refresh 🔄 icon on the extension card

### Settings not saving

1. Make sure you're entering valid credentials
2. Check for red error messages under fields
3. Try reloading the extension
